# hominid-sim

An evolution and extinction simulator for humans and Neanderthals, built with
Panda3D and PyTorch.

Every individual carries 22 inheritable traits (strength, intelligence, tool
use, cold tolerance...). A neural network trained per scenario predicts each
one's chance of survival. The populations evolve across hundreds of thousands of
years until they one goes extinct.

Written as my A-level Computer Science project at 16/17... so please don't judge the quality too much...

## Run

```sh
cd src
python hominid_sim.py
```
